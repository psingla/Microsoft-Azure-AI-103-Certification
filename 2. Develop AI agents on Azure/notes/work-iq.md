# Microsoft Work IQ

**Remember: Work IQ = workplace context for agents through a CLI or MCP server.**

- Connects AI assistants to Microsoft 365 data: **emails, meetings, documents, Teams messages, and people**.
- Supports natural-language queries to ground answers in relevant workplace information.
- **CLI:** `workiq ask` asks questions; **MCP server:** `workiq mcp` exposes tools to AI assistants.

Example questions:
- What did my manager say about the project deadline?
- Find my recent Q4 planning documents.
- Summarize today's messages in the Engineering channel.
- Who is working on Project Alpha?

**Access:** tenant-admin consent is required for the CLI/MCP server permissions. Work IQ is in public preview.

Source: [Microsoft Work IQ](https://github.com/microsoft/work-iq).
