# Foundry Workflows

**Remember: Foundry visual workflows retire; build new workflows with Microsoft Agent Framework (MAF).**

- **Foundry Workflows (preview):** visual, declarative sequences that orchestrate AI agents and business logic, including branching and human approvals.
- **Retirement date: December 1, 2026.**
- **New workflows:** use Microsoft Agent Framework.
- **Existing workflows:** follow Microsoft's migration guide before retirement.

This retirement applies to the Foundry Workflows feature, not to workflow orchestration in Microsoft Agent Framework.

Source: [Foundry workflows and migration guidance](https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/workflow) (verified 2026-10-06).
