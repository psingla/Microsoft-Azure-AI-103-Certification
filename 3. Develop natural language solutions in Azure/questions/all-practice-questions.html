Azure Language MCP server

Q1. What is the primary role of the Azure Language MCP server?
Show answer and explanation

Correct answer: B. The server exposes Azure Language capabilities, such as language detection, NER, and PII redaction, as tools an agent can use. It is not a model training or deployment service.

Q2. How does an agent determine which Azure Language MCP tool to call when processing a user's prompt?
Show answer and explanation

Correct answer: B. The host discovers available tools through its MCP client and makes their descriptions and input schemas available to the agent. The agent selects a suitable tool; the MCP server executes the requested tool rather than independently choosing one from the original prompt.

Q3. When building a Python client application, how do you reference a Foundry agent when calling the OpenAI Responses API?
Show answer and explanation

Correct answer: B. With the OpenAI client obtained from the Foundry project client, pass extra_body={"agent_reference": {"name": "<agent-name>", "type": "agent_reference"}}. This references an existing configured agent.

Q4. What authentication method is used when connecting the Azure Language MCP server to a Foundry agent?
Show answer and explanation

Correct answer: B. In the documented key-based connection setup, configure the Azure Language resource key using the Ocp-Apim-Subscription-Key header. Store the key securely, never in source code. This setup is distinct from Microsoft Entra authentication used by a direct SDK client.

Text and speech translation

Q5. What function of an Azure Translator TextTranslationClient object should you use to convert the Chinese word "你好" to the English word "Hello"?
Show answer and explanation

Correct answer: B. translate converts the meaning of text into another language. transliterate changes its writing system, and get_supported_languages lists supported languages rather than converting text.

Q6. What function of an Azure Translator TextTranslationClient object should you use to convert the Russian word "спасибо" in Cyrillic characters to "spasibo" in Latin characters?
Show answer and explanation

Correct answer: C. transliterate changes the script while preserving the word's approximate pronunciation. "Spasibo" is Russian represented in Latin characters, not its English translation ("thank you").

Q7. Which Azure Speech SDK object should you use to specify the language(s) into which you want speech translated?
Show answer and explanation

Correct answer: B. SpeechTranslationConfig specifies translation target languages through target_languages or add_target_language(). AudioConfig selects audio input/output, while SpeechConfig is the general recognition/synthesis configuration.
