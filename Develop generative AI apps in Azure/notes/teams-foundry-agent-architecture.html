Design constraints to carry into implementation

Personal chat, one stream

Teams streaming is supported in 1:1 chats, with one concurrent streaming response per chat. Use a non-streaming fallback for other scopes.

Buffer, don't flood

For manual REST delivery, Microsoft recommends buffering tokens for about 1.5-2 seconds. Updates contain accumulated text; SDK helpers handle the streaming mechanics.

Keep the boundaries secure

Validate Teams activity tokens, use Entra authentication and least-privilege access to Foundry, and isolate conversation state. Organization-wide publishing needs admin approval.
