Sora 2 video generation

Q1. What video durations does Sora 2 support?
Show answer and explanation

Correct answer: B. The documented Sora 2 video generation API accepts durations of 4, 8, or 12 seconds. The default is 4 seconds; it does not accept arbitrary durations within a continuous range.

Q2. What is required when using a reference image with Sora 2?
Show answer and explanation

Correct answer: B. The input_reference image dimensions must exactly match the requested video size: 720x1280 for portrait or 1280x720 for landscape. Matching aspect ratio alone is insufficient. A human face is not required.

Q3. What is the remix feature used for in Sora 2?
Show answer and explanation

Correct answer: B. Remix makes targeted changes to a previously generated video, using it as the starting point rather than creating an unrelated video from scratch. Do not assume that arbitrary uploaded videos are supported as remix inputs.

Azure Content Understanding

Q4. What kinds of AI solution is Azure Content Understanding designed to help you build?
Show answer and explanation

Correct answer: B. Azure Content Understanding processes multimodal unstructured content and extracts information. Translation chatbots and image generation are different capabilities, not its primary purpose.

Q5. Which graphical tool should you use to create an Azure Content Understanding project?
Show answer and explanation

Correct answer: C. Content Understanding Studio provides a graphical workflow to create a project, define a schema, and test a custom analyzer. Visual Studio is a development environment; Azure Machine Learning studio is not the dedicated Content Understanding project tool.

Q6. What should you define for the information you want to extract from content?
Show answer and explanation

Correct answer: A. A field schema defines the information to extract, including field names, types, and descriptions. An index organizes data for retrieval, and a cluster is not an extraction specification.

Azure Document Intelligence

Q7. You need to extract text and table structure from documents with varying formats, without identifying specific labeled fields. Which Document Intelligence model should you use?
Show answer and explanation

Correct answer: B. The layout model extracts text and document structure, including tables. The read model focuses on text recognition; the invoice model extracts invoice-specific fields that are not required here.

Q8. You are building a labeled custom extraction model in Azure Document Intelligence. What training artifacts are required for the labeled-data workflow when training with the REST API?
Show answer and explanation

Correct answer: B. The labeled training dataset includes source documents, corresponding OCR and label files, and the field schema file. Studio can generate these artifacts during labeling. This question concerns labeled custom extraction, not classifier training or legacy unlabeled workflows.

Q9. A company processes both invoices and receipts and wants a single endpoint that routes each document to the correct extraction model. What should it use?
Show answer and explanation

Correct answer: C. Composition or classification plus routing selects an extraction model according to document type. A read model does not route documents, and a standalone custom neural extractor is not a document-type routing layer.

Composed models combine custom extraction models; the v4.0 compose workflow requires an explicit classifier. A standalone classifier identifies types but does not extract fields: application routing must invoke the chosen extractor. For prebuilt invoice and receipt models, expose that orchestration through your own endpoint rather than assuming they can be directly composed.

Azure AI Search and knowledge mining

Q10. Which component of an Azure AI Search solution is scheduled to extract and enrich data to populate an index?
Show answer and explanation

Correct answer: A. An indexer reads source data, runs an attached skillset when enrichment is configured, and populates the search index. It can run on a schedule. A projection shapes or maps output; a query retrieves indexed content.

Q11. Which service supports built-in AI skills in Azure AI Search?
Show answer and explanation

Correct answer: B. Several built-in AI enrichment skills use Foundry Tools, including OCR and language analysis capabilities. Azure Functions can host custom skills; Azure Cosmos DB can serve as a data source. Not every built-in skill calls a billable AI service: utility skills such as Shaper are different.

Q12. Which kind of knowledge store projection results in a relational data schema for extracted fields?
Show answer and explanation

Correct answer: C. Table projections store shaped enrichment data as rows and columns in Azure Table Storage, with related tables in a projection group. Object projections store JSON in Blob Storage; file projections store files such as extracted images.

"Relational" describes the tabular shape and relationships here, not deployment of a SQL relational database. Knowledge store projections are also distinct from search index projections.
