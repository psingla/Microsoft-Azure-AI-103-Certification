Case 1 of 6

Retail launch across two markets

10 questions

Shared case facts: Use these requirements for questions 1-10. Each question is independent of earlier answers.

  • A retailer is launching an interactive shopping assistant. The EU business permits inference anywhere in Microsoft's EU data zone but not outside it. The North American launch is a separate environment with its own data and access configuration.
  • The assistant answers from a centrally maintained catalog and warranty index that changes daily. It must cite the applicable product and policy version. Customer-specific prices are obtained from an authenticated application service rather than a daily catalog export.
  • Traffic is seasonal and initially difficult to forecast. The business wants consumption-based inference, secretless Azure-hosted authentication, and a staged release with predefined quality, safety, cost, and latency gates.
  • The application already produces the desired friendly writing style with a short prompt. Source descriptions arrive in several languages, and raw customer identifiers must not be retained in evaluation datasets.

1. Location and purchase model

The EU team is selecting the inference deployment for unpredictable launch traffic. Procurement will not approve reserved processing capacity during the pilot. Inference may move within the approved EU data zone, and the business wants to use that flexibility rather than constrain processing to one region. Which deployment is the best match?

Choose ONE answer.

  1. Global Standard in a resource created in Europe.
  2. Data Zone Standard configured for the EU data zone.
  3. Data Zone Provisioned configured for the EU data zone.
  4. Global Provisioned with EU document storage.
Answer and explanation for question 1

Answer: B

Why: Data Zone Standard combines consumption billing with inference constrained to the specified data zone.

  • A: Resource location does not make a Global deployment's processing EU-only.
  • C: Provisioned capacity conflicts with the pilot's purchasing constraint.
  • D: Both the global processing scope and reserved-capacity model conflict with the requirements.

2. Launch model decision

Choose ONE answer.

  2. L, because it has the highest task success.

  4. M, because it is the only measured configuration satisfying both gates.
Answer and explanation for question 2

Answer: D

Why: M passes both hard thresholds; neither lower cost nor higher accuracy excuses failing a required gate.

  • C: A voice-generation capability does not replace speech recognition.
  • D: OCR is not an audio transcription pipeline.
  • E: Natural-sounding output does not prove correctness or permission.

60. Validate the retrieval stage before blaming generation

An evaluation set has query-to-document relevance labels. After an indexing change, answers become incomplete because relevant procedural passages are missing from the candidate set. The drafting model and prompt are unchanged. Which evaluation and remediation focus is most appropriate first?

Choose ONE answer.

  1. Measure only final-answer fluency and buy a larger generation model.
  2. Increase response length while retaining the same incomplete evidence.
  3. Use document-retrieval evaluation against the relevance labels, inspect ingestion/chunking/filter coverage, and fix candidate retrieval before retesting generation.
  4. Apply semantic ranking after discarding all but the same incorrect first result.
Answer and explanation for question 60

Answer: C

Why: Labeled retrieval evaluation isolates the failed stage. Generation and late reranking cannot reliably recover passages never retrieved.

  • A: Fluency does not measure evidence recall.
  • B: More generated text does not supply missing source facts.
  • D: Cannot recover a relevant passage removed before ranking.
