# DP-420: Enrollment and Study Guide

**Remember: build -> secure and optimize -> add AI and analytics.**

DP-420 is **Building AI Applications with Azure Cosmos DB**, leading to
**Microsoft Certified: Azure Cosmos DB AI Developer Associate**. The certification
name and level changed on **October 6, 2026**; older specialty preparation material
may not cover the current objectives.

## Why DP-420?

**Goal: understand where custom Cosmos DB-based agent memory fits, not just pass the exam.**

- Compare custom Cosmos DB-based memory with **Foundry Agent Service's managed
  Memory capability** and **retrieval-based approaches**.
- Learn the trade-offs to evaluate: memory lifecycle, retrieval, partitioning,
  consistency, security, latency, cost, and operational responsibility.
- Understand the **Cosmos DB toolkit** better and where its tools fit in an
  agent architecture.

Treat these as related design choices to investigate, not mutually exclusive
options: a custom memory architecture can also use retrieval.

## Enrollment

- Start at the [official certification page](https://learn.microsoft.com/en-us/credentials/certifications/azure-cosmos-db-developer-specialty/?practice-assessment-type=certification).
- Use **Schedule exam** to book through Pearson VUE. Microsoft recommends a
  **personal Microsoft account**, so exam records remain accessible if you leave
  your employer or school.
- Price depends on the exam country/region; confirm it during booking.
- Exam: **100 minutes**, proctored; passing score: **700 or higher**.
- Renewal is available at no cost through an online Microsoft Learn assessment.

## Study priorities

Use the [official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-420)
as the checklist. Objectives effective **October 6, 2026**:

| Domain | Weight | Focus |
| --- | --- | --- |
| Design and develop database solutions | 40-45% | Consistency, RUs and throughput, SDKs, CRUD and queries, transactions, TTL, concurrency, data modeling, partition keys, change feed, Agent Kit |
| Secure, optimize, and deploy database solutions | 30-35% | Authentication and authorization, network security, data masking, backup/restore, multi-region availability, query/index tuning, diagnostics, Fleet management |
| Implement AI and analytics capabilities | 20-25% | Full-text, vector and hybrid search, RAG, agent memory and conversation state, Fabric mirroring, T-SQL/Spark, Cosmos DB Spark connector |

## Preparation plan

1. **Scope:** Turn the current study-guide objectives into a checklist.
2. **Learn:** Follow the [official training options](https://learn.microsoft.com/en-us/credentials/certifications/exams/dp-420#two-ways-to-prepare)
   and [Azure Cosmos DB documentation](https://learn.microsoft.com/en-us/azure/cosmos-db/).
3. **Build:** Practice partitioning, SDK operations, change feed, security,
   performance tuning, AI retrieval, agent memory, and Fabric integration.
   Expected background includes **C# or Python** application development.
4. **Check:** Take the [official practice assessment](https://learn.microsoft.com/en-us/credentials/certifications/azure-cosmos-db-developer-specialty/practice/assessment?assessment-type=practice&assessmentId=104&practice-assessment-type=certification);
   revisit weak objectives and explain why each answer is right or wrong.
5. **Rehearse and book:** Try the [exam sandbox](https://go.microsoft.com/fwlink/?linkid=2226877),
   then schedule. Practice scores guide revision but do not guarantee a pass.

Verified against Microsoft Learn on **October 16, 2026**. Recheck objectives and
booking details before enrolling.
